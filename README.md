# odin-recipes

My first project from [The Odin Project](https://www.theodinproject.com/) - Foundations Course.

## Description
A simple, clean recipe website built with only HTML.

This project is about learning the basics of HTML structure, boilerplate, links, images, and file organization. No CSS yet - just pure HTML as per the assignment.

The site has a homepage with links to 3 of my favorite recipes.
